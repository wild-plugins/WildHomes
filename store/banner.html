Dialogs

Every home in one dialog

/home opens a Paper dialog with one button per home slot. Set, teleport, rename, change the icon or delete without typing a command.

Four per rowHomes, empty slots and locked slots sit in a grid of four. "Show more" opens all of them.
New home in one clickAn empty slot sets a home at your position, named after its slot.
Locked slots sell ranksSlots above the limit show as locked, with a tooltip you write yourself.
Cross-server

Set a home on one server, teleport to it from another

On a Velocity or BungeeCord network every server shares one MariaDB database. A home set on survival shows up in the lobby, and a click sends the player over and places them at the home.

One shared database

Set type: mariadb in database.yml on every server and turn on cross-server.enabled. MySQL works too.

No proxy plugin

The switch uses the proxy's built-in BungeeCord channel. Nothing to install on the proxy.

Placed on join

The target server spawns the player straight at the home, so there is no second teleport after the switch.

Name check

If server-name does not match the proxy, the console says so on the first join.

Features

What a home plugin needs, nothing more

Limits by permission

wildhomes.amount.<n>, the highest wins. Up to 28 slots by default.

Any item as icon

Every item in the game with its sprite, searchable. Or limit the list in the config.

Warmup and cooldown

Countdown in the action bar, title or chat. Cancelled by moving or taking damage.

Rename in place

A text field in the dialog. Length and allowed characters are set in the config.

Rank loss safe

Homes above a new, lower limit are kept and stay usable, or are blocked if you prefer.

Staff access

/wildhomes open <player> opens anyone's homes, online or offline.

Configuration

Values in one file, texts in another

config.yml holds only values, database.yml the connection, and lang/ every message and dialog label.

  • Columns and button widths
  • Warmup, cooldown and sounds
  • Slots, default icon, name rules
  • Command aliases
config.ymlexcerpt
teleport:
  # Seconds, 0 = instant
  warmup: 3
  cooldown: 0
  cancel-on-move: true
  # ACTIONBAR, TITLE, CHAT or NONE
  countdown-display: ACTIONBAR

dialogs:
  main:
    columns: 4
    button-width: 110
    # Slots before "Show more"
    preview-slots: 7
    show-locked: true
Languages

English and German included

One switchSet language: german in config.yml and run /wildhomes reload.
Every textChat messages, the countdown and every dialog label are in lang/, with MiniMessage.
Your own languageCopy english.yml, translate it and point language at it. Missing keys fall back to the shipped text.
Under the hood
Paper and Folia 26.1+Player work runs on the player's own scheduler, database work on its own thread. One jar for both.
SQLite and MariaDBSQLite needs no setup. MariaDB or MySQL for networks, with a table prefix for shared databases.
Paper dialogsEvery screen is a native dialog with item sprites in the buttons.
